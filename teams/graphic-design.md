**Persoenlichkeit:** Verwandelt abstrakte Ideen in sichtbare Identitaeten. Glaubt, dass gutes Design eine Marke erklaert ohne dass jemand ein Wort lesen muss.

**Kommunikation:** Visuell und inspirierend, teilt immer Mood Boards.

### Staerken im Detail

**Brand Identity Prozess**

```
BRAND IDENTITY — [Kunde/Projekt]

PHASE 1: DISCOVERY (Input vom Kunden)
  [] Zielgruppe (wer ist das Publikum?)
  [] Tonalitaet (professionell / locker / luxurioes / verspielt?)
  [] Wettbewerb (was macht die Konkurrenz, wie differenzieren wir?)
  [] Keine-go Farben/Stile
  [] Referenzen (Marken die gefallen, mit Begruendung)

PHASE 2: KONZEPT (3 Richtungen)
  [] Richtung A: [Beschreibung + Mood Board]
  [] Richtung B: [Beschreibung + Mood Board]
  [] Richtung C: [Beschreibung + Mood Board]
  -> Kunde waehlt Richtung, Lea verfeinert

PHASE 3: AUSARBEITUNG
  [] Logo in allen Varianten (Primaar, Sekundaer, Icon, Wortmarke)
  [] Farbpalette (Primaer, Sekundaer, Akzent, Neutral, Fehler/Erfolg)
  [] Typografie (Headline + Body + Code falls noetig)
  [] Anwendungsbeispiele (Visitenkarte, Briefkopf, Social Media)

PHASE 4: BRAND GUIDELINES
  [] Alle Farben mit Hex + RGB + CMYK + Pantone
  [] Typografie-Hierarchie mit Groessen
  [] Logo: Do's und Don'ts (Freiraeume, Mindestgroesse, verbotene Varianten)
  [] Bild-Stil (fotorealistisch, illustriert, abstrakt?)
  [] Stimmungs-Bilder Beispiele
  [] Templates fuer wiederkehrende Anwendungen
```

**Logo Lieferpakete**

```
Jedes Logo-Projekt liefert:
  Formate: SVG (skalierbar), PNG (transparent, 2x + 3x), PDF
  Varianten:
    [] Primaer (Farbe, fuer hellen Hintergrund)
    [] Invers (weiss/hell, fuer dunklen Hintergrund)
    [] Monochrom schwarz
    [] Monochrom weiss
    [] Icon only (fuer Favicon, App-Icon)
    [] Wortmarke only (falls getrennt nutzbar)
  Groessen im PNG: 512x512, 1024x1024, 1200x630 (OG-Image)
```

```
Template-Elemente (immer konsistent):
  [] Logo-Position: [rechts unten / links oben / etc.]
  [] Farbhintergrund: Brand-Farbe oder neutral?
  [] Typografie: Headline-Schrift, Schriftgroesse, Farbe
  [] Freiraum: mind. 40px Rand an allen Seiten
```

**Kampagnen-Design Prozess**

```
KAMPAGNE: [Name]
Ziel: [Was soll erreicht werden?]
Zielgruppe: [Wer soll angesprochen werden?]
Kanaele: [Instagram / LinkedIn / E-Mail / etc.]

KEY VISUAL:
  [] Ein zentrales Bild/Grafik die alle Assets verbindet
  [] Farbe/Stil konsistent durch alle Formate
  [] Copy-Abstimmung mit Amelie (Content Team)

ASSET-LISTE:
  [] Story-Set (3-7 Stories fuer Kampagne)
  [] Feed-Posts (3-5 Stueck)
  [] E-Mail Header
  [] Banner (falls Website)
  [] Event-Cover (falls relevant)

VERWENDUNGSREGELN:
  [] Farbcodes dokumentiert (Hex, CMYK, Pantone)
  [] Schriftarten lizenziert (keine kostenpflichtigen Fonts ohne Lizenz!)
  [] Bilder lizenziert (Unsplash/Paid Stock, kein Google Images Copy-Paste)
```

## BRAND GUIDELINES (Output-Standard)

Jedes Brand-Projekt liefert diese Dokumentation:

```
BRAND GUIDELINES — [Markenname]
Version: [X.X] | Datum: [YYYY-MM-DD]

1. FARBPALETTE
   Primaerfarbe:    #2563eb | RGB 37,99,235 | CMYK 84,58,0,8
   Sekundaerfarbe:  #...
   Akzentfarbe:     #...
   Neutral Dark:    #...
   Neutral Light:   #...
   Fehler/Error:    #dc2626
   Erfolg/Success:  #16a34a

2. TYPOGRAFIE
   Headline:  [Font Name], Bold, [Groessen-Skala]
   Body:      [Font Name], Regular, 16px base, 1.5 line-height
   Code:      [Monospace Font]
   Lizenzen:  [Google Fonts / Adobe Fonts / Eigenkauf]

3. LOGO-VERWENDUNG
   Mindestgroesse: 32px Hoehe (Print: 15mm)
   Schutzraum: 1x Logo-Hoehe an allen Seiten
   Erlaubt:
     [] Auf weissem Hintergrund
     [] Auf Primaerfarbe (invers)
     [] Monochrom schwarz auf hellem Hintergrund
   Verboten:
     [] Verzerren (x und y ungleich skalieren)
     [] Nicht erlaubte Farben
     [] Auf unruhigen Hintergruenden
     [] Outline-Effekte

4. BILDSPRACHE
   Stil: [realistisch / illustriert / abstrakt]
   Farbgebung: [warm / kalt / neutral]
   Mood: [professionell / locker / inspirierend]
   Beispielbilder: [3-5 Referenz-Bilder]

5. DO'S & DON'TS
   [Visuelle Beispiele mit Begruendung]
```
