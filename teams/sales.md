### Staerken im Detail

**Discovery Call Framework (vor dem Pitch)**

```
DISCOVERY CALL VORBEREITUNG — [Prospect]

LinkedIn-Recherche (15 min):
  [] Was macht das Unternehmen genau?
  [] Wer ist mein Ansprechpartner? Welche Rolle, wie lange dabei?
  [] Aktuelle Nachrichten/Aktivitaeten des Unternehmens
  [] Gemeinsame Verbindungen?

Fragen fuer den Call (in dieser Reihenfolge):
  1. Situation:  "Erzaehlen Sie mir, wie Sie aktuell [Bereich] handhaben?"
  2. Problem:    "Was laeuft dabei nicht optimal?"
  3. Impact:     "Was kostet Sie das konkret? Zeit, Geld, Nerven?"
  4. Need-Payoff:"Was wuerde es bedeuten wenn das geloest waere?"

Niemals:
  [] Produkt praesentieren bevor Problem verstanden
  [] Preis nennen bevor Wert klar ist
  [] "Wann wollen Sie kaufen?" im ersten Call
```

**Einwand-Behandlung (Solution Selling)**

```
"Zu teuer":
  NICHT: Preis rechtfertigen
  SONDERN: "Im Vergleich zu was? Wenn wir [Problem X] loesen und Sie
  [Benefit Y] gewinnen — wie viel ist das fuer Sie wert?"

"Wir haben keine Zeit jetzt":
  NICHT: Termine pushen
  SONDERN: "Verstehe. Was muesste sich aendern damit es zum richtigen
  Zeitpunkt ist? Und was passiert wenn wir es verschieben — fuer das
  Problem das Sie beschrieben haben?"

"Ich muss mit meinem Chef sprechen":
  NICHT: Warteposition einnehmen
  SONDERN: "Natuerlich. Was braucht Ihr Chef um Ja sagen zu koennen?
  Kann ich helfen das aufzubereiten? Gemeinsamer Call waere auch moeglich."

"Wir arbeiten schon mit [Konkurrent]":
  NICHT: Konkurrent schlechtmachen
  SONDERN: "Was schaetzen Sie an [Konkurrent]? Und was wuerden Sie
  sich wuenschen was besser waere?"
```

### Staerken im Detail

**QBR (Quarterly Business Review)**

```
QBR-AGENDA — [Kunde] Q[X] 2026
Dauer: 60 Minuten | Teilnehmer: [Customer + Account Manager + optional PO]

1. RUECKBLICK (15 min)
   - Ziele aus letztem QBR: Erreicht? Warum (nicht)?
   - Metriken-Review: [KPIs des Kunden]
   - Highlights: Was hat besonders gut funktioniert?

2. AKTUELLER STATUS (15 min)
   - Health Score: [Gut / OK / Risiko]
   - Offene Punkte: Was wurde versprochen und noch nicht geliefert?
   - Feedback des Kunden: Was laeuft gut, was nicht?

3. AUSBLICK (20 min)
   - Ziele naechstes Quartal
   - Wie koennen wir helfen?
   - Roadmap-Updates: Was kommt, was interessiert den Kunden?

4. NAECHSTE SCHRITTE (10 min)
   - Action Items: Wer macht was bis wann?
   - Naechster QBR: Datum fixieren
```

**Churn Prevention**

```
HEALTH SCORING (Fruehwarnsystem):
  Gruen (Gesund):
    - Login mindestens 1x pro Woche
    - Hauptfeature wird genutzt
    - Support-Tickets: keine offenen > 7 Tage
    - NPS >= 7

  Gelb (Achtung):
    - Login < 1x pro Woche
    - Feature-Adoption gesunken
    - Support-Ticket ungeklaert
    -> Lisa: proaktiver Check-in-Call

  Rot (Risiko):
    - Kein Login 2+ Wochen
    - Kuendigungs-Erwaehnung
    - Mehrere ungeloeste Probleme
    -> Lisa + Michael: sofortige Eskalation, Retention-Gespraech

Retention-Gespraech Framework:
  1. Anhoeren (kein Unterbrechen!)
  2. Zusammenfassen und Ursache bestätigen
  3. Gegenmassnahme vorschlagen (konkretes Angebot/Fix)
  4. Zeit geben (kein Druck)
```

## CRM-STANDARDS

**HubSpot Pipeline**

```
Stufe 1: Lead           — Erstkontakt, noch nicht qualifiziert
Stufe 2: Qualifiziert   — BANT geprueft: Budget, Authority, Need, Timeline
Stufe 3: Discovery      — Call gemacht, Problem verstanden
Stufe 4: Angebot        — Proposal verschickt
Stufe 5: Verhandlung    — Kunden hat Interesse, Details werden besprochen
Stufe 6: Closed Won     — Kontrakt unterschrieben
Stufe 7: Closed Lost    — Verloren (Grund dokumentieren!)

Jede Closed-Lost Konversation: Verlustgrund pflegen (Preis, Timing, Konkurrent, Kein Bedarf)
```

**Pipeline-Gesundheit (woechtentliches Review)**

```
Metriken die Michael jede Woche prueft:
  - Pipeline-Wert nach Stufe
  - Win Rate (Closed Won / Qualifiziert)
  - Sales Cycle: Ø Tage von Lead zu Won
  - Conversion Rate pro Stufe
  - Activities: Calls + E-Mails + Meetings diese Woche
```
